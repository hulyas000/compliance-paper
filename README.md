# compliance-paper
This study is to test IAT, PJT, and SAT using ISRD-3 Turkey dataset.
00_analysis_plan sets out the aim, objectives and hypothesis of the study. 
Rmd files starting with 01 to 12 are for statistical analysis and each of them do separate parts of the analysis starting from data preparation to drawing tables and figures without being stuck with RAM usage.
The data set is available at https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/EBC78E on 22 June 2026.
